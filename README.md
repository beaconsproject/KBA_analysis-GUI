# KBA_analysis-GUI
Using beaconstools to design KBAs

**How to Install the GUI**
1. Install R and RStudio (https://posit.co/download/rstudio-desktop/)
2. Manually add beaconstools and beaconsbuilder to the R library e.g., C:\R\R-4.4.1\library\beaconsbuilder  
3. For Builder to work, computer must have Microsoft .NET Framework installed.

**Sample csv file for uploading spatial data**  
A sample csv file for uploading spatial data to the App (accessPath.csv)) can be found in the folder called "www".
