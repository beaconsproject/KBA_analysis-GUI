
## Create Builder input

Builder constructs KBAs starting from a seed which in this case is a single catchment. Prior to run Builder, a seedlist and a neighbour table need to be generated and save in the input_Builder folder. 


### Using the app
- **Specify output directory** : Select a destination folder where outputs generated by the app will be saved. When a destination folder is chosen, the app checks if Builder input files
are already present in the specified directory. If input files are already present, the app will automatically upload these files into the environment, making them immediately available 
for use. If input files are missing, the app will generate the necessary files and save them in the selected directory. This approach ensures users save time by reusing existing input 
files while allowing the app to generate any new files required for the builder. To start a new analysis, you need to make sure the destination folder is empty. 
- **Specify Strahler index to create seedlist** : Seed catchments can be restricted to headwater catchments by indicating Strahler Order 1. 
- **Specify area target for building conservation areas (sq.m)** : Set the area target for building conservation areas (sq.m).

The **Create Builder Input** initiates the file creation process based on the parameters and selections specified in the app. 
This button is essential for starting the generation of Builder input files, which will be saved in the directory specified by the user. 

### Output

The seedlist (seed.csv) and neighbour table (neighbour.csv) are created and saved in the Builder_input folder.

A geopackage named **KBA_analysis** is also initialized in the output folder at this stage and will serve to hold all intermediates layers generated in the analysis.
